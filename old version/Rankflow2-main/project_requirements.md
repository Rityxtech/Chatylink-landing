# RankFlow Landing Page - Job Application Assessment Requirements

## 1. Project Overview
- **Project Type**: SaaS Product Landing Page (Website Development Assessment).
- **Core Technology**: Next.js, HTML, Tailwind CSS, minimal/purposeful JavaScript.
- **Deadline**: **1:00 AM (Midnight), 5th May 2026 (PKT)**.

## 2. Core Requirements
- **Structure**: A complete SaaS homepage.
- **Design (UI/UX)**: Strong, clean, modern, polished, and production-ready.
- **Copywriting/Content**: Clear messaging and sensible content flow.
- **SEO**: Proper SEO implementation (Title tags, meta descriptions, semantic HTML, structured data).
- **Analytics**: Placeholder setup for website tracking and analytics scripts (e.g., Google Analytics, Tag Manager, Pixel).
- **Code Quality**: Clean, organized, maintainable code architecture.
- **Styling**: Effective and advanced use of Tailwind CSS.
- **Javascript**: Sensible, purposeful usage (e.g., interactive elements like mobile menu, accordions, animations - avoid bloat).

## 3. Assessment & Grading Criteria
The hiring team will grade the submission based on:
1. Overall website design quality.
2. The clarity and strength of the message.
3. Page structure and user experience.
4. Code architecture and cleanliness.
5. Use of Tailwind CSS (look for consistency, customized design tokens, responsive breakpoints).
6. Use of JavaScript (functionality without unnecessary complexity).
7. SEO readiness (metadata, semantic tags, alt text).
8. Attention to detail (hover states, transitions, error handling, accessibility/a11y).
9. **Creativity and effort *beyond* the basic requirements.** (THIS IS THE MOST CRITICAL METRIC).

## 4. AI Usage Policy & Differentiator Strategy
- **Allowed**: Full usage of AI is allowed.
- **Warning**: Generic AI-generated designs, basic templates, or single-prompt outputs will negatively affect the score.
- **Winning Strategy**: We must intelligently refine the output, avoid standard "AI-looking" Tailwind boilerplate, use custom color palettes, implement micro-interactions (e.g., Framer Motion or smooth CSS transitions), and ensure the final result feels original, premium, and human-crafted.

## 5. Deliverables / Submission Format
1. **Live Link**: A deployed URL of the Next.js application (e.g., deployed via Vercel).
2. **Email Body Report** (DO NOT ATTACH AS A FILE! Must be in the email body):
   - What was built.
   - Which AI tool(s) were used.
   - How AI was used in the workflow.
   - Any additional improvements/extra work added beyond the basic requirements.
