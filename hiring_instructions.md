# Next.js Website Development Assessment Instructions

## Overview
Create a complete landing page for a SaaS product. 

*Note: While the prompt mentions "Next.js Website Development Assessment" and "simple HTML", we will be implementing this using our standard, high-performance React + Vite + Tailwind CSS stack to ensure a modern, component-driven architecture.*

## Requirements
- **Complete SaaS homepage structure:** Hero section, features, testimonials, pricing, footer, etc.
- **Strong, clean, and modern UI/UX design:** Must not look generic. Needs originality, polish, and a production-ready feel.
- **Clear messaging and content flow:** Copy should be persuasive and naturally structured.
- **Proper SEO implementation:** Meta tags, semantic HTML (header, main, section, footer, h1-h6 progression).
- **Placeholder setup for website tracking and analytics scripts:** E.g., Google Analytics / Tag Manager mock scripts in the head.
- **Clean, organized, and maintainable code:** Component-based architecture.
- **Effective use of Tailwind CSS:** purposeful design, spacing, typography, and responsive patterns.
- **Sensible and purposeful use of JavaScript:** e.g., sticky headers, mobile menu toggles, simple scroll animations, or tabbed interfaces.

## Assessment Criteria
- Overall website design quality
- Clarity and strength of the message
- Page structure and user experience
- Code architecture and cleanliness
- Use of Tailwind CSS
- Use of JavaScript
- SEO readiness
- Attention to detail
- Creativity and effort beyond the basic requirements (What makes it stand out beyond a single prompt output).

## Submission Details
- **Live link:** Where the website can be viewed.
- **Short report in email body:**
  - What was built.
  - Which AI tool(s) were used.
  - How AI was used in the workflow.
  - Additional improvements/extra work added beyond basic requirements.
